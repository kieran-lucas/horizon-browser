# Horizon Visual Direction v2

## Core vibe

**Ethereal blue anime-tech minimalism**

Horizon should feel:

- calm
- cold
- intelligent
- slightly supernatural
- premium
- airy
- bright
- spacious
- restrained

The UI should combine a premium modern browser with subtle Japanese/anime symbolism, without becoming a fan-art theme or an otaku skin.

---

## Color language

Primary atmosphere:

- ice white
- cool white
- powder blue
- mist blue
- soft luminous blue

Blue should behave like ambient energy rather than a flat fill.

Avoid:

- cyberpunk blue
- neon cyan
- purple AI gradients
- oversaturated surfaces
- full-screen blue tint

Blue accents may appear in:

- active tab
- Horizon wordmark
- protection state
- selected controls
- orbital lines
- soft halos
- icon highlights
- background ribbons

The overall surface should remain mostly cool-white and very light.

---

## Composition

Use strong negative space.

The main New Tab composition should follow a clear vertical hierarchy:

1. small character/brand sigil
2. large Horizon wordmark
3. subtle tagline
4. primary search field
5. compact shortcut row

The center should feel open and intentional, not crowded.

Do not fill empty space just because it is available.

---

## Character branding

Character imagery should function as a restrained brand signature.

Rules:

- small scale
- clean crop
- soft halo
- low visual aggression
- never behave like wallpaper
- never dominate the interface
- repeat subtly across hero mark, favicon/tab and profile only where useful

The intended feeling is:

**brand sigil / character mark**, not illustration.

Anime influence should remain symbolic and atmospheric.

---

## Background art language

Preferred motifs:

- folded light planes
- soft wave ribbons
- orbital curves
- thin arcs
- faint particles
- luminous halos
- asymmetrical geometry
- Japanese editorial microcopy

The background should feel gently alive but never noisy.

Preferred visual associations:

- sky
- ice
- light
- energy field
- Limitless-like spatial depth
- soft motion
- distance
- horizon

Avoid:

- literal anime backgrounds
- manga panels
- large character illustrations
- stars everywhere
- gaming HUD
- sci-fi dashboards
- heavy technical grid systems

---

## Browser chrome

Browser chrome should remain visually restrained so that the New Tab art can carry the emotional layer.

Use:

- cool white / very light gray surfaces
- thin borders
- moderate radius
- small shadows
- clean spacing
- crisp typography
- minimal decoration

Avoid:

- heavy glass
- strong blur
- thick borders
- oversized controls
- overly decorative toolbar elements

The browser should still feel like a real premium productivity product.

---

## Active tab

Active tab prominence: medium.

The active tab should:

- lift slightly
- feel clearly selected
- use subtle blue emphasis
- remain integrated with the tab strip

Avoid making it look like a detached floating card.

---

## Typography

Use one coherent UI type family initially.

Target feeling:

- dense
- confident
- clean
- modern
- slightly rounded
- premium
- readable

Lexend-like typography remains an acceptable baseline.

The Horizon wordmark may have stronger visual weight than normal UI text.

Use microcopy with wider tracking where appropriate.

---

## Shortcut tiles

Shortcut tiles should feel like soft utility tiles.

Structure:

browser surface
→ shortcut card
→ icon well
→ brand icon

Properties:

- low contrast
- soft border
- restrained shadow
- generous but not excessive radius
- curated appearance
- optical balance between different brand icons

Brand colors may remain, but the row must never feel rainbow-like.

---

## Motion

Motion should feel:

- seamless
- premium
- slightly inertial
- calm
- responsive

Input feedback must happen immediately.

Animation should complete the state change, not delay it.

Avoid:

- bounce-heavy motion
- exaggerated overshoot
- decorative looping animation
- large parallax
- slow cinematic transitions

---

## Emotional target

The final product should feel:

**calm, cold, intelligent, slightly supernatural**

A useful style ratio:

- 70% premium minimal browser UI
- 15% Japanese editorial design
- 10% ethereal sci-fi / spatial energy
- 5% character branding

---

## Most important rule

**Restraint.**

Nothing should shout.

Blue must be present without flooding the screen.

Character branding must be recognizable without dominating.

Background art must feel alive without becoming wallpaper noise.

Shortcuts may retain brand identity without producing color clutter.

Chrome must remain quiet.

---

## Visual source precedence

For visual/UI decisions, use this order:

1. latest approved visual reference in `docs/design/reference/`
2. this file: `docs/design/art-direction-v2.md`
3. `DESIGN_SYSTEM.md`
4. original superprompt visual guidance

Newer approved visual references override older visual guidance only.

Architecture, engine, security, performance and feature requirements from the original project specification remain authoritative.
